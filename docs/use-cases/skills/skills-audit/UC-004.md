# Use Case

## Overview

| Field | Value |
|---|---|
| ID | UC-004 |
| Name | Contributor runs real test suite |
| Requirement reference | FR-005, FR-006 |
| Goal | `npm test` executes unit + integration tests against real filesystem ops and exits 0 |
| Primary actor | Contributor |

## Supporting Actors
- CI / release workflow

## Preconditions
- Repo cloned; `bun install` done (bun is the primary toolchain per AGENTS.md)

## Trigger
Contributor runs `npm test` (or `bun test`).

## Main Flow

| Step | Actor / system | Action | Outcome |
|---|---|---|---|
| 1 | contributor | runs `npm test` | delegates to `bun test` |
| 2 | bun:test | runs `test/unit/` — pure fn tests (paths, transforms, inference, semver) | unit results reported |
| 3 | bun:test | runs `test/integration/` — CLI commands vs `fs.mkdtemp` dirs | real file trees asserted |
| 4 | bun:test | exits 0 | contributor sees pass counts; regression protection exists |

## Alternative Flows
### A1
- Trigger: run on Windows (no symlink support)

| Step | Action | Outcome / return to main flow |
|---|---|---|
| A1.1 | integration tests skip symlink assertions on win32 | copy-path assertions still run |

## Exception Flows
### E1

| Trigger | Handling | Resulting state / message |
|---|---|---|
| bun not installed | `npm test` fails with clear "bun required" message | contributor installs bun per AGENTS.md |

## Postconditions
- Placeholder test script replaced permanently
- FR-006 defect fixes each carry a regression test

## Business Rules
- Tests never touch real `~/.claude` — all integration uses temp dirs + env overrides where available
- No network access in tests (`upgrade` npm-view path tested via pure helpers only)

## Data
- `test/unit/*.test.ts`, `test/integration/*.test.ts`
- `package.json` `scripts.test`

## Acceptance Criteria
- [ ] `npm test` exits 0 and reports >0 unit + >0 integration cases
- [ ] Integration tests create temp dirs and clean them up
- [ ] No test depends on files outside the repo + temp dirs
