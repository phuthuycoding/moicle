# Use Case

## Overview

| Field | Value |
|---|---|
| ID | UC-007 |
| Name | Specialist agents for research and ideation |
| Requirement reference | FR-009, FR-010 |
| Goal | `@researcher` and `@brainstormer` exist as utility agents; ideation frameworks survive the `/brainstorm` removal |
| Primary actor | Claude Code user |

## Supporting Actors
- Package maintainer

## Preconditions
- TASK-012 done — both agent files exist under `assets/agents/utilities/` following agent convention
- Updated package installed

## Trigger
User needs structured ideation or broad research — invokes `@brainstormer` / `@researcher`, or a skill routes there.

## Main Flow

| Step | Actor / system | Action | Outcome |
|---|---|---|---|
| 1 | user | asks to brainstorm ("brainstorm first-principles…") | `@brainstormer` agent engages; offers the 6 frameworks |
| 2 | agent | runs chosen framework on the challenge | structured ideation output — same as the old command delivered |
| 3 | user | asks for research ("find best practice for X") | `@researcher` agent explores breadth, reports findings + trade-offs with sources |

## Alternative Flows
### A1
- Trigger: a skill needs ideation internally (TRACK Phase 0, marketing-brand routing)

| Step | Action | Outcome / return to main flow |
|---|---|---|
| A1.1 | skill references `@brainstormer` instead of `/brainstorm` | same capability via agent, no dead reference |

## Exception Flows
### E1

| Trigger | Handling | Resulting state / message |
|---|---|---|
| A file still points at `/brainstorm` | TC-014 fails | caught before publish |

## Postconditions
- `/brainstorm` command gone; its 6 frameworks live inside `@brainstormer`
- Two new agents follow every agent convention (frontmatter, arch reference, principles block, match-the-project-first)

## Business Rules
- Removed commands must not leave dangling references anywhere in shipped assets or docs
- New agents reuse the conventions all 16 existing agents follow — no bespoke structure

## Data
- `assets/agents/utilities/researcher.md`, `assets/agents/utilities/brainstormer.md`
- Former `assets/commands/brainstorm.md` content (6 frameworks)

## Acceptance Criteria
- [ ] Both agent files exist with convention-conformant structure
- [ ] `@brainstormer` contains all 6 frameworks: First Principles, SCAMPER, Design Thinking, Working Backwards, 5 Whys, Rapid Fire
- [ ] Zero `/brainstorm` references outside `.works/`; prior reference sites now point at `@brainstormer` or are removed
