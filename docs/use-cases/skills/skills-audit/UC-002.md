# Use Case

## Overview

| Field | Value |
|---|---|
| ID | UC-002 |
| Name | Vietnamese/shorthand triggers still auto-invoke the right skill |
| Requirement reference | FR-002, FR-004 |
| Goal | Existing trigger phrases — incl. Vietnamese — keep working after the TRACK merge and challenge fix |
| Primary actor | Claude Code (skill auto-invocation) |

## Supporting Actors
- npm end-user (types the phrase)

## Preconditions
- Updated `feature-build` and `challenge` skills installed

## Trigger
User types a phrase matching a merged description trigger, e.g. "làm track này" or "check kĩ hơn".

## Main Flow

| Step | Actor / system | Action | Outcome |
|---|---|---|---|
| 1 | user | types "làm track này" | phrase matches `feature-build` description (TRACK trigger carried over) |
| 2 | Claude Code | auto-invokes `feature-build`, selects TRACK mode | tracked-loop workflow starts as before the merge |
| 3 | user | types "check kĩ hơn" | phrase now matches `challenge` description (newly added) |
| 4 | Claude Code | auto-invokes `challenge` | self-critique workflow runs |

## Alternative Flows
### A1
- Trigger: English trigger used instead

| Step | Action | Outcome / return to main flow |
|---|---|---|
| A1.1 | user types "tracked loop" | same TRACK mode invocation — bilingual triggers coexist |

## Exception Flows
### E1

| Trigger | Handling | Resulting state / message |
|---|---|---|
| Phrase matches two descriptions | prevented by FR-003 audit | deterministic single-skill match |

## Postconditions
- All former `feature-track` triggers live in `feature-build`'s description
- `challenge` description contains the Vietnamese triggers CLAUDE.md documents

## Business Rules
- Every pre-merge trigger phrase must survive the merge verbatim
- A phrase may appear in exactly one skill/command description

## Data
- `feature-build` SKILL.md description: former feature-track phrases incl. `"bắt đầu loop"`, `"làm track này"`, `"brainstorm rồi làm track"`
- `challenge` SKILL.md description: `"check kĩ hơn"`, `"soi lại"`, `"phản biện"`, `"tối ưu chưa"`, `"có lặp code không"`, `"did I overengineer"` per CLAUDE.md table

## Acceptance Criteria
- [ ] `feature-build` description contains every phrase previously in `feature-track` description
- [ ] `challenge` description contains the Vietnamese phrases documented in CLAUDE.md
- [ ] No phrase appears in two descriptions
