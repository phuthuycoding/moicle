# Use Case

## Overview

| Field | Value |
|---|---|
| ID | UC-001 |
| Name | Fresh install ships deduplicated asset set |
| Requirement reference | FR-001, FR-002, FR-004, FR-009 |
| Goal | `moicle install` delivers exactly 10 skills, 2 commands, 18 agents — no `doc.md`, no `brainstorm.md`, no `feature-track` |
| Primary actor | npm end-user |

## Supporting Actors
- Claude Code (consumes installed skills/commands)

## Preconditions
- moicle package built (`dist/` + `assets/` present)
- Target dir (`./.claude/` or `~/.claude/`) exists or is creatable

## Trigger
User runs `moicle install --project` (or `--global`, or equivalent cursor/codex target).

## Main Flow

| Step | Actor / system | Action | Outcome |
|---|---|---|---|
| 1 | user | runs `moicle install --project` | installer enumerates `assets/` |
| 2 | system | copies/symlinks agents, commands, skills, architecture | commands dir has 2 entries; skills flattened to 10 dirs incl. `feature-build`; 18 agents |
| 3 | system | prints install summary | counts match shipped assets |
| 4 | user | runs `moicle list --project` | lists 2 commands, 10 skills, 18 agents; no `doc`, no `brainstorm`, no `feature-track` |

## Alternative Flows
### A1
- Trigger: Cursor target selected

| Step | Action | Outcome / return to main flow |
|---|---|---|
| A1.1 | install with `--target cursor` | rules/skills generated from same asset tree; no doc command or track skill emitted |

## Exception Flows
### E1

| Trigger | Handling | Resulting state / message |
|---|---|---|
| Target dir not writable | installer reports failure, exits non-zero | partial copies cleaned or reported; error surfaced, not swallowed |

## Postconditions
- Installed tree contains no `doc.md` and no `feature-track` skill
- `feature/` group flattener still emits `feature-build` correctly

## Business Rules
- Skill flattening `<group>-<action>` unchanged for retained items
- Removed assets must not appear in any install target

## Data
- `assets/commands/`: bootstrap.md, marketing.md
- `assets/skills/`: 10 skill dirs (challenge, cleanup, docs/sync, feature/build, fix/bug, fix/incident, marketing/brand, marketing/content, research/explore, review/code)

## Acceptance Criteria
- [ ] `moicle install --project` into a temp dir yields exactly 2 commands + 10 skills + 18 agents
- [ ] `feature-build` skill dir present; `feature-track` absent
- [ ] `moicle list` output agrees with the installed tree
