# Use Case

## Overview

| Field | Value |
|---|---|
| ID | UC-006 |
| Name | Agent files carry no editor-specific fields |
| Requirement reference | FR-008 |
| Goal | All 16 agent frontmatter blocks contain only `name` + `description` — no `model:` pin |
| Primary actor | Package maintainer |

## Supporting Actors
- Claude Code (honors `model:` when present, defaults to `inherit` when absent)

## Preconditions
- moicle assets tree checked out

## Trigger
A maintainer or test inspects `assets/agents/**/*.md` frontmatter.

## Main Flow

| Step | Actor / system | Action | Outcome |
|---|---|---|---|
| 1 | maintainer | strips `model:` line from all 16 agent files | frontmatter = name + description only |
| 2 | Claude Code | reads installed agent | no `model` field → defaults to `inherit` (session model) |
| 3 | codex/antigravity/cursor transform | processes agent | unchanged output — fields were already dropped |

## Alternative Flows
### A1
- Trigger: user wants a model pin for their own install

| Step | Action | Outcome / return to main flow |
|---|---|---|
| A1.1 | user adds `model:` to their installed copy | local customization — package stays neutral |

## Exception Flows
### E1

| Trigger | Handling | Resulting state / message |
|---|---|---|
| A `model:` line is left behind in one file | test TC-013 fails | CI catches it before publish |

## Postconditions
- Zero `model:` keys across agent frontmatter
- Claude installs behave as `inherit` — Anthropic's recommended default

## Business Rules
- Agent files stay editor-neutral; editor-specific fields belong to transforms/install output, never to source assets

## Data
- `assets/agents/developers/*.md` (6), `assets/agents/utilities/*.md` (10)

## Acceptance Criteria
- [ ] `grep -l "model:" assets/agents/**/*.md` returns nothing
- [ ] Every agent frontmatter still parses with `name` + `description` present
